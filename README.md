# LivePhoto Link

**LivePhoto Link** 是一款專為 Android 設計的區域網路即時照片傳輸與大螢幕展示應用程式（單一 APK 同時支援手機傳送端與平板接收端），針對 **Samsung Galaxy S24 Ultra** 與 **Samsung Galaxy Tab S11** 的實際拍攝與展示流程打造。

您可繼續使用手機原生的**三星相機**拍照，拍攝完成後 App 會於背景自動偵測新照片，透過本地區域網路加密傳輸原始檔案至平板，平板隨即以沉浸式全螢幕自動更新為最新照片，全程無需手動分享、確認或操作平板。

---

## 核心功能特色

### 手機傳送端（Sender）
- **保留三星原生相機**：透過 `MediaStore` 與 `ContentObserver` 監控 `DCIM/Camera` 新增照片，不需改用第三方相機。
- **精準過濾與防漏防重**：僅傳送連線後新拍攝的相機照片（JPEG / PNG / HEIC / DNG），自動排除截圖、下載圖片、`.pending` 與回收桶檔案，不同步歷史相簿。
- **完整寫入驗證**：確認 `IS_PENDING == 0`、檔案大小連續檢查穩定且可正常讀取後才開始傳輸，避免 50MP / 200MP 多幀 HDR 尚未寫完就送出損壞檔案。
- **前景服務與佇列重試**：採用符合 Android 14/15 規範的 `dataSync` 前景服務與常駐通知，支援 10 張以上連續拍攝佇列、斷線偵測、指數退避自動重連與失敗重試。
- **快速預覽模式（選用）**：拍攝 50MP / 200MP 等大型照片時，可先傳送小尺寸預覽圖讓平板 1～3 秒內立即顯示，再於背景補傳原始檔案並無縫替換。

### 平板接收端（Receiver）
- **即時自動全螢幕更新**：收到並通過 SHA-256 校驗的新照片後，於單一 Activity 透過 Compose `StateFlow` 即時更新畫面，不重啟 Activity、不閃爍。
- **沉浸式展示與螢幕常亮**：自動隱藏狀態列與導覽列；預設保持螢幕常亮（可於設定關閉）。
- **高解析度安全解碼與 EXIF 方向**：以 Coil 3 搭配視窗尺寸安全降採樣解碼，避免 200MP 照片造成 OOM；自動依 EXIF 旋轉顯示，預設 `ContentScale.Fit` 完整顯示不裁切不拉伸；支援 DNG 預覽提取。
- **手勢與歷史瀏覽**：支援橫向/直向旋轉、雙指縮放、雙擊放大/還原、**向右滑動查看前一張照片**（最新照片在最右側，與系統相簿操作直覺一致）；點擊畫面才顯示資訊與控制列（連線狀態、接收時間、原始解析度、檔案大小、暫停自動切換、返回最新照片）。
- **連線階段緩存與自動清除**：預設為「連線階段緩存」模式，照片於連線期間暫存於快取供隨時滑動回看，**中斷連線或關閉應用程式時自動刪除暫存檔**；亦可於設定切換為「永久保存於 App 專用空間」或「同時儲存至系統相簿（`Pictures/LivePhotoLink`）」。

### 區域網路、安全與配對
- **完全離線本地運作**：支援同 Wi-Fi 與**手機行動熱點**，不依賴任何外部伺服器、雲端或網際網路。
- **三種配對方式**：
  1. **Android NSD / mDNS 自動搜尋**（同區網自動列出平板）
  2. **QR Code 掃描配對**（離線 CameraX + ZXing，免 Play 服務）
  3. **手動輸入 IP + 連接埠 + 6 位數配對碼**
- **端對端加密與完整性驗證**：
  - 採用 **6 位數配對碼（PBKDF2-HMAC-SHA256）+ 雙向 HMAC-SHA256 身分驗證 + 臨時 ECDH（secp256r1）金鑰交換 + AES-256-GCM 逐幀加密**，拒絕任何陌生裝置連線。
  - 64 KB 串流傳輸並於接收端先寫入 `.part` 暫存檔，比對檔案大小與 **SHA-256 雜湊值**完全一致後才原子更名並回傳 `PHOTO_ACK`，絕不將不完整檔案顯示出來。

## 技術架構與選型說明

| 類別 | 採用技術 | 說明 |
| --- | --- | --- |
| 語言與 UI | Kotlin + Jetpack Compose + Material 3 | 原生 Android，綠色系 Material 3 主題，支援深色模式與繁體中文 |
| 非同步與狀態 | Kotlin Coroutines + StateFlow | 單向資料流，畫面旋轉與新照片抵達皆不重啟 Activity |
| 照片偵測 | Android MediaStore + ContentObserver | 搭配定期補檢與寫入穩定檢查，相容三星相機批次更新 |
| 背景執行 | Foreground Service (`dataSync`) + WifiLock + WakeLock | 符合 Android 14/15 規範，確保背景穩定傳輸 |
| 服務探索 | Android NSD (`_livephotolink._tcp.`) | 自動發現同區網或熱點中的接收端 |
| 加密傳輸 | 自訂分幀 TCP + ECDH (P-256) + AES-256-GCM + SHA-256 | 使用標準 JCA 內建加密演算法，免自簽憑證相容性問題，亦可在 JVM 完整進行端對端整合測試 |
| 圖片解碼 | Coil 3 + AndroidX ExifInterface | 依螢幕尺寸自動降採樣避免 200MP OOM，完整支援 EXIF 方向與無閃爍替換 |
| QR 配對 | CameraX + ZXing Core | 完全離線掃描與產生 QR Code，不依賴 Google Play Services |

## 安裝方式

### APK 輸出路徑
建置完成後的 Debug APK 位於：
```text
app/build/outputs/apk/debug/app-debug.apk
```

### 透過 ADB 安裝（Windows）
1. 在手機與平板開啟「開發人員選項」→「USB 偵錯」，並接上電腦授權。
2. 執行以下指令安裝至裝置：
```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```
也可直接將 `app-debug.apk` 複製到手機與平板中點擊安裝（需允許安裝未知來源應用程式）。

### 從原始碼建置（Windows 11）
需求環境：JDK 17、Android SDK（API 35）。
```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

## 初次設定與權限指南（Samsung One UI 必看）

### 1. 手機端（Galaxy S24 Ultra）
1. 開啟 **LivePhoto Link** → 選擇 **「傳送端（手機）」**。
2. 開啟「即時照片傳送服務」開關時，請允許以下必要權限：
   - **相片和影片（`READ_MEDIA_IMAGES`）**：偵測 `DCIM/Camera` 新拍照片。
   - **通知（`POST_NOTIFICATIONS`）**：顯示前景服務常駐通知。
   - **媒體位置（`ACCESS_MEDIA_LOCATION`）**：讀取未遭系統移除 GPS 資訊的原始 EXIF 檔案。
   - （僅在點擊「掃描 QR Code」時才會要求相機權限。）
3. **Samsung One UI 背景穩定設定**（強烈建議）：
   - 在首頁點擊 **「電池不受限制」** → 允許忽略電池最佳化。
   - 或至手機 `設定 → 應用程式 → LivePhoto Link → 電池` → 選擇 **「不受限制」**，避免開啟三星相機時 One UI 凍結背景連線。

### 2. 平板端（Galaxy Tab S11）
1. 開啟 **LivePhoto Link** → 選擇 **「接收端（平板）」**。
2. 確認平板已連上與手機相同的 Wi-Fi，或連上**手機開啟的行動熱點**。
3. 畫面會立即顯示 **配對 QR Code**、**6 位數配對碼** 與 **區域網路 IP / 連接埠（預設 48910）**。

## 配對與使用步驟

1. **連線配對（任選一種方式）**：
   - **掃描 QR Code（最快）**：手機端點擊「掃描 QR Code」，對準平板畫面即可完成配對並自動連線。
   - **NSD 自動搜尋**：手機與平板連在同一 Wi-Fi 後，手機端「區域網路自動搜尋到的平板」會自動出現平板名稱，點擊後輸入平板顯示的 6 位數配對碼即可。
   - **手動輸入 IP**：點擊「手動輸入 IP」，輸入平板顯示的 IP、連接埠（預設 `48910`）與 6 位數配對碼。
2. **開始拍攝**：
   - 確認手機與平板皆顯示綠燈「已連線」。
   - 直接按 Home 鍵或切換至**三星原生相機**開始拍照。
   - 每拍一張照片，平板將自動於全螢幕立即更新顯示！
3. **平板端操作**：
   - **點擊螢幕**：顯示 / 隱藏控制列（連線狀態、接收時間、解析度、檔案大小、配對資訊與設定）。
   - **雙指縮放 / 雙擊畫面**：檢視照片細節（200MP 細節亦可安全縮放）。
   - **左右滑動**：瀏覽先前接收的照片。
   - **暫停自動切換 / 返回最新照片**：檢視舊照片時可暫停自動跳轉，隨時一鍵回到最新拍攝畫面。

## 常見問題（FAQ）

**Q1：現場沒有 Wi-Fi 路由器，只有手機和平板能用嗎？**  
可以！開啟手機的「行動熱點」，讓平板連上手機熱點即可（即使手機關閉行動數據、完全沒有網際網路也能正常傳輸）。若熱點環境下 mDNS 搜尋較慢，直接使用 QR Code 或手動輸入平板顯示的 IP 即可秒連。

**Q2：為什麼拍完照退到背景幾分鐘後就沒有自動傳送？**  
Samsung One UI 預設會將背景 App 休眠。請務必到手機端首頁點選「電池不受限制」，並在 `設定 → 應用程式 → LivePhoto Link → 電池` 設為 **「不受限制」**，同時確認通知列有顯示「LivePhoto Link 傳送端運作中」。

**Q3：為什麼不會同步手機裡原本的舊照片？**  
依預設設計，服務啟動時會記錄起始時間戳，僅傳送連線／啟動服務後新拍攝的照片，避免把整個相簿灌入平板。

**Q4：拍攝 200MP 照片傳送需要較久時間怎麼辦？**  
200MP 原檔通常達 30～60 MB，傳輸與三星相機後製寫入需要數秒。您可在手機端「設定」中開啟 **「快速預覽模式」**，平板會先於 1～2 秒內顯示預覽圖，原檔傳完後再無縫替換。

**Q5：手機原始照片會被修改或刪除嗎？**  
絕不會。傳送端僅以唯讀方式讀取原始檔案串流，不會對手機相簿進行任何修改或刪除。
